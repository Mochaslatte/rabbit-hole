      Rabbit Hole

      Rabbit Hole is a game where you travel from one Wikipedia article to another using only the links inside the articles. Reach the target with the fewest clicks and the fastest time.

        Waiting for the host to start the round…

        Type any article name and pick a suggestion, or press Random route. Only blue links inside the article text count. The timer pauses while pages load. Challenge a friend: after a run, copy the challenge link and they get the same route. During a run, press B to go back or H for a hint.
